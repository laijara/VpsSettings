# 🛡️ Standalone VPN Server (3x-ui + MTProxy)

Полностью автономный скрипт развертывания личного VPN-сервера по концепции **Infrastructure as Code (IaC)**. 

Главная архитектурная особенность проекта — **нулевая зависимость от внешних Docker-реестров**. Все необходимые Docker-образы хранятся прямо в репозитории в виде скомпилированных `.tar` архивов (вендоринг). Это гарантирует, что сервер поднимется, даже если Docker Hub заблокирован, а исходные репозитории авторов удалены.

## ✨ Ключевые особенности
* **Stateless-архитектура:** Никаких вшитых паролей и баз данных в репозитории. Конфигурации и ключи шифрования генерируются на лету при "холодном" старте.
* **Offline Docker Images:** Образы `3x-ui` и `mtproxy` загружаются из локальных файлов через `docker load`.
* **One-Liner Deploy:** Вся инфраструктура разворачивается одной командой в консоли чистого сервера.
* **Авто-конфигурация:** Фаервол (`ufw`), Docker, Docker Compose и генерация FakeTLS секрета для Telegram-прокси происходят автоматически.

## 🚀 Быстрая установка

Для развертывания потребуется абсолютно чистый сервер на базе **Ubuntu / Debian** с доступом в интернет.

Подключитесь к серверу по SSH и выполните одну команду:

```bash
curl -sL [https://raw.githubusercontent.com/laijara/VpsSettings/main/install.sh](https://raw.githubusercontent.com/laijara/VpsSettings/main/install.sh) | bash
```

### Что происходит под капотом?
1. Скрипт устанавливает `git`, `curl` и `ufw`.
2. Клонирует этот репозиторий вместе с тяжелыми `.tar` образами в директорию `/root/vpn-server`.
3. Устанавливает актуальную версию Docker и плагин Docker Compose.
4. Распаковывает локальные образы в кэш Докера.
5. Динамически генерирует `docker-compose.yml` и уникальный `MTG_SECRET` для MTProxy.
6. Поднимает контейнеры и выводит готовые доступы в консоль.

## 🔑 Доступы по умолчанию (Post-Install)

После успешного завершения работы скрипта, вы получите в консоли всю необходимую информацию:

* **Панель управления 3x-ui:** `http://<IP_ВАШЕГО_СЕРВЕРА>:2053`
  * Логин по умолчанию: `admin`
  * Пароль по умолчанию: `admin` *(Обязательно смените после первого входа!)*
* **Telegram MTProxy:** Готовая ссылка формата `tg://proxy?...` выведется прямо в терминал.

## 🛠️ Для разработчиков: Обновление образов

Так как проект использует Git Large File Storage (LFS) для хранения образов, для обновления версий панелей выполните следующие шаги на локальной машине с Docker:

1. Скачайте свежие версии образов:
```bash
docker pull ghcr.io/mhsanaei/3x-ui:latest
docker pull nineseconds/mtg:1
```

2. Сделайте дамп в `.tar` архивы, заменив старые файлы в папке `images/`:
```bash
docker save -o images/3x-ui.tar ghcr.io/mhsanaei/3x-ui:latest
docker save -o images/mtproxy.tar nineseconds/mtg:1
```

3. Отправьте изменения в репозиторий:
```bash
git add images/
git commit -m "chore: update docker images"
git push
```
