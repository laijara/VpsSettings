# 🛡️ Автономная настройка VPN & Telegram Proxy

Скрипт для быстрой и полностью автоматической настройки личного VPN-сервера и защищенного прокси для Telegram на чистом сервере Ubuntu/Debian. 

Скрипт решает проблемы со строгим NAT (как на хостингах Aeza), автоматически пробивает нужные порты в фаерволе, устанавливает легковесные службы (потребление всего ~20 МБ ОЗУ) и защищает сервер от брутфорс-атак, меняя стандартный порт SSH. Все установочные файлы автономны и хранятся прямо в этом репозитории в папке `src`.

---

## 🚀 Быстрая установка

Для установки вам понадобится абсолютно чистый сервер на **Ubuntu** или **Debian**.
Подключитесь к серверу по SSH и выполните эту команду:

```bash
git clone [https://github.com/laijara/VpsSettings.git](https://github.com/laijara/VpsSettings.git) /root/VpsSettings && cd /root/VpsSettings && bash setup.sh
````

Скрипт отработает за 1-2 минуты. В конце установки в консоль будет выведен готовый конфиг для WireGuard и кликабельная FakeTLS-ссылка для Telegram.

-----

## 🔐 ВАЖНО: Подключение после установки

Скрипт автоматически меняет порт SSH со стандартного `22` на `8922` для защиты от автоматических ботов-сканеров.

Для следующих подключений к вашему серверу используйте команду с указанием нового порта:

```bash
ssh -p 8922 root@IP_ВАШЕГО_СЕРВЕРА
```

## 👥 Как добавлять новых пользователей

### 1\. Добавление клиента в WireGuard (VPN)

Скрипт установки работает как удобное интерактивное меню. Чтобы добавить новый телефон или компьютер:

1.  Подключитесь к серверу по SSH (через порт 8922).
2.  Перейдите в папку проекта и запустите установщик из исходников:
    ```bash
    cd /root/VpsSettings
    ./src/wireguard/wireguard-install.sh
    ```
3.  В появившемся меню введите цифру `1` (Add a new client).
4.  Введите имя клиента латиницей без пробелов (например, `iphone` или `laptop`).
5.  На остальные вопросы просто нажимайте `Enter`.
6.  Скрипт мгновенно создаст профиль, выведет **QR-код** для сканирования с телефона и напишет путь к текстовому файлу (например, `/root/iphone.conf`) для настройки ПК.

### 2\. Добавление клиента в Telegram (MTProxy)

Прокси написан на легком Python и работает из системной директории `/opt/mtprotoproxy`. Чтобы выдать доступ друзьям с уникальными ключами:

1.  **Сгенерируйте новый пароль (секрет)** для пользователя, выполнив команду:

    ```bash
    xxd -l 16 -p /dev/urandom
    ```

    *(Скопируйте полученную 32-значную строку из букв и цифр)*

2.  **Откройте файл конфигурации** прокси:

    ```bash
    nano /opt/mtprotoproxy/config.py
    ```

3.  **Добавьте пользователя** в словарь `USERS`. Соблюдайте синтаксис Python (запятые между пользователями). Пример:

    ```python
    PORT = 8443
    USERS = {
        "admin": "СТАРЫЙ_СЕКРЕТ_ИЗ_УСТАНОВКИ",
        "friend": "ВАШ_НОВЫЙ_32_ЗНАЧНЫЙ_СЕКРЕТ"
    }
    ```

    Сохраните файл (`Ctrl+O`, `Enter`) и закройте редактор (`Ctrl+X`).

4.  **Перезапустите службу**, чтобы изменения вступили в силу:

    ```bash
    systemctl restart mtproxy
    ```

5.  **Сформируйте ссылку для пользователя.**
    Для обхода блокировок мы используем FakeTLS (маскировка под https://www.google.com/search?q=google.com).
    Шаблон ссылки выглядит так:
    `tg://proxy?server=IP_СЕРВЕРА&port=8443&secret=ee<НОВЫЙ_СЕКРЕТ>7777772e676f6f676c652e636f6d`

    *Просто вставьте сгенерированный секрет после букв `ee`, замените `IP_СЕРВЕРА` на ваш IP и отправьте ссылку.*

## 🛠 Полезные команды для управления

**Проверка статуса служб:**

  * Прокси Telegram: `systemctl status mtproxy`
  * WireGuard VPN: `wg show`

**Перезагрузка служб (если что-то зависло):**

  * Прокси Telegram: `systemctl restart mtproxy`
  * WireGuard VPN: `systemctl restart wg-quick@wg0`
  * SSH служба: `systemctl restart sshd`
